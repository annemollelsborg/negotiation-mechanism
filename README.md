# Negotiation Mechanism for Climate MARL

Data generation and surrogate model training follow the [ciceroscm-surrogate](ciceroscm-surrogate/) baseline. This repo extends the MARL experiment with a three-stage episode structure: **proposal**, **evaluation**, and **climate action**.

## Setup

```bash
make init
```

## MARL experiment

```bash
python src/marl_experiment.py
```
